# M3 导出管线（MP4 三种编码、校验、断点续跑）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 MP4 导出：MPEG-4 Part 2、H.264、H.265（仅硬件）三种视频编码 + AAC 48 kHz 音频，复用 M2 的时间线求值、合成与混音，支持预设、进度、取消、检查点续跑、写前与写后校验、导出对话框，并保证预览/导出画面一致、音画时长偏差不超过一帧。

**Architecture:** 导出是 `videoeditor_media` 中的离线管线：`TimelineCompositor`（从 M2 `TimelineRenderWorker` 抽出的唯一合成实现）把每一帧画进离屏 D3D11 纹理，`OfflineFrameRenderer` 回读为 RGBA；`VideoEncoder`/`AudioEncoder` 用 libavcodec 就地编码（不启动 `ffmpeg.exe`），`SegmentWriter` 每约 8 秒写一个独立 MP4 分段，`ExportCheckpoint` 原子记录完成分段；全部分段由 `Mp4Assembler` 按精确帧/采样偏移重封装为最终 MP4。`ExportController` 在 `videoeditor_ui` 中把同步 `ExportPipeline` 放进工作线程，QML `ExportDialog` 只绑定属性与调用方法。

**Tech Stack:** C++20、Qt 6.8.x（Core/Gui/Quick/QuickControls2/Qml/Test）、FFmpeg 7.1 LGPL（libavformat/libavcodec/libavutil/libswscale/libswresample）、Direct3D 11、GoogleTest、CMake 3.27+、MSVC 2022、Windows x64。

**Spec:** [docs/superpowers/specs/2026-11-14-video-editor-design.md](../specs/2026-11-14-video-editor-design.md)（M3 对应 §5.2、§5.4、§6–§9、§10、§11.1–§11.3、§13）

## Global Constraints

- 仅 Windows 10 21H2+ / Windows 11 x64；MSVC 2022 19.4x；CMake ≥ 3.27；C++20；源码 UTF-8（`/utf-8`）。
- Qt 固定 6.8.x；FFmpeg 固定 7.1.x **LGPL**。应用不得链接 GPL 组件或 libx264/libx265；GPL `ffmpeg.exe` 只用于生成测试素材，不得复制进应用目录、不得在导出时启动。
- 图形后端只能是 D3D11；导出合成必须走与预览相同的 `TimelineCompositor`，不得新增“仅导出”的视觉分支。导出允许每帧一次 GPU→CPU 回读（离线路径，性能预算内），预览路径的“无 CPU 回读”约束不变。
- 时间统一 `int64_t` 微秒；帧率用 `Rational{num, den}`；导出帧时间戳用整数 `frame * 1e6 * fps.den / fps.num` 计算，禁止浮点累加。
- 内部音频固定 48 kHz、浮点、双声道；导出 AAC-LC 48 kHz 双声道；混音与导出都不得削波（限幅上限 0.98）；音画时长偏差 ≤ 1 帧。
- 导出为 CFR：每个视频帧恰好一个 packet，`max_b_frames = 0`，时间基 `1/fps`；H.265 只允许硬件编码，无可用硬件时禁用并说明原因，绝不静默改成 H.264。
- 原始素材只读；工程快照在导出开始时按值冻结；工程与检查点原子写入（`QSaveFile`）。
- 面向用户的字符串用中文；标识符、日志、注释用英文。
- 单元测试不得强制依赖 GPU 或编码硬件：无法创建 D3D11 设备时 `GTEST_SKIP()`；无 H.265 硬件时相关测试 `GTEST_SKIP()` 并在消息中写原因。

## Design Decisions

1. **编码器与许可证策略（明确 ID）。**
   - 软件、始终可用：MPEG-4 Part 2 用 libavcodec 原生 `mpeg4`（LGPL，YUV420P）。
   - H.264 硬件顺序：`h264_nvenc`（NVIDIA）、`h264_qsv`（Intel）、`h264_amf`（AMD）、`h264_mf`（Media Foundation，`hw_encoding=1`）。
   - H.264 软件顺序：`h264_mf`（`hw_encoding=0`，Windows 自带 Media Foundation 软件编码 MFT，专利由系统许可覆盖）、`libopenh264`（BtbN LGPL 构建内置，BSD-2-Clause；若发布方不能确认 Cisco 专利授权，默认不选它，仅作为探测到的备选并在 UI 显示“OpenH264（软件）”）。`VIDEOEDITOR_H264_SOFTWARE=mf|openh264` 可强制首选，默认 `mf`。
   - H.265 硬件顺序：`hevc_nvenc`、`hevc_qsv`、`hevc_amf`、`hevc_mf`（全部 `hw_encoding=1`/硬件 MFT）。**不使用** `libkvazaar`，即使构建中存在；规格要求 H.265 仅硬件。
   - 探测方式不是在表里“看起来有”，而是 `avcodec_find_encoder_by_name` + 用目标分辨率/帧率/像素格式真正 `avcodec_open2` 并编码 1–3 帧、收到至少 1 个 packet；失败记录原因并继续下一个候选。
2. **就地编码，不启动 CLI。** `VideoEncoder`/`AudioEncoder` 直接使用 libavcodec；`SegmentWriter`/`Mp4Assembler` 使用 libavformat。`ffmpeg.exe` 仍只服务代理生成与测试素材。
3. **系统内存 NV12/YUV420P 输入。** 硬件编码器接受系统内存 NV12（内部自行上传），因此合成帧回读一次 RGBA 后由 libswscale 转 NV12；MPEG-4/OpenH264 转 YUV420P。这样 H.264/H.265 的三种硬件厂商路径与软件路径共用一套编码循环，避免为 NVENC/QSV/AMF 各写一套 D3D11 互操作；1080p30 RGBA 回读约 250 MB/s，远低于 PCIe 与内存带宽。
4. **复用预览合成。** 从 `TimelineRenderWorker` 抽出 `TimelineCompositor`（设备、转换器、解码源缓存、字幕光栅化、逐层绘制）。`TimelineRenderWorker` 只保留共享纹理环形缓冲与信号；`OfflineFrameRenderer` 用同一个 `TimelineCompositor` 画到离屏 RGBA 纹理再回读。预览/导出因此共享同一求值、同一层序、同一字幕实现。
5. **CFR + 零 B 帧。** 导出编码器统一 `max_b_frames=0`、`time_base={fps.den, fps.num}`，每个视频帧一个 packet；分段切点只取决于整数帧号，DTS==PTS，重封装不会因重排跨段。
6. **分段检查点而不是“可追加 MP4”。** MP4 的 `moov` 在文件尾，崩溃后单文件不可读。导出每约 8 秒写一个独立 MP4 分段（`<output>.parts/segment_00000.mp4`），每个分段 `av_write_trailer` 后即完整；检查点原子记录已完成分段数与总帧/采样数；最终由 `Mp4Assembler` 逐分段 demux、按精确偏移重封装，输出普通（非 fragmented）MP4。
7. **音频独立成一条连续轨道。** 视频按分段写 MP4；音频不按视频分段切，而是从采样 0 到总采样数只写一个 `<parts>/audio.mp4`，因此整条时间线只有一次 AAC 编码器预延迟，不会在续跑边界插入 1024 个 priming 采样。续跑时视频分段复用，音频从头重编（混音+编码远快于视频渲染）；`AudioTrackWriter` 使用 `use_editlist=0` 保存原始 packet，最终由 `Mp4Assembler` 统一写 `skip_samples`/`discard_padding`。`SegmentRouter` 只路由视频 packet，并按帧范围核对每个分段的 packet 数。
8. **精确音画长度。** `totalFrames = round(durationUs * fps.num / (1e6 * fps.den))`，`totalSamples = round(totalFrames * 48000 * fps.den / fps.num)`；最后一帧音频不足 1024 采样时补静音，并在最终 MP4 的最后一个音频 packet 上写 `AV_PKT_DATA_SKIP_SAMPLES` 的 `discard_padding`；首个音频 packet 写 `skip_samples = encoder initial_padding`。容器时长因此与视频对齐。
9. **H.265 门禁。** `detectEncoders()` 结果缓存在进程内；H.265 无硬件时 `EncoderCatalog::selectEncoder` 返回空并给出中文原因，`ExportPipeline::run` 在创建任何输出文件前失败；`ExportController` 在 UI 中禁用 H.265 并显示原因。

```cpp
{
```

```cpp
#pragma once

#include <cstdint>
#include <optional>

#include <QJsonObject>
#include <QList>
#include <QMetaType>
#include <QString>

#include "TimeBase.h"
#include "Timeline.h"

namespace VideoEditor {

enum class ExportVideoCodec { Mpeg4Part2, H264, H265 };
enum class ExportQuality { Low, Medium, High };
enum class ExportRateControl { Bitrate, Quality };

struct ExportSettings {
    ExportVideoCodec codec = ExportVideoCodec::H264;
    int width = 1920;
    int height = 1080;
    Rational fps{30, 1};
    ExportRateControl rateControl = ExportRateControl::Quality;
    ExportQuality quality = ExportQuality::Medium;
    // 0 means "derive from quality"; otherwise 100..200000 kbps.
    int bitrateKbps = 0;
    bool preferHardware = true;
    bool burnSubtitles = true;
    bool writeSrt = false;
    QString outputPath;
    QString srtPath;
    // Empty = automatic selection by EncoderCatalog.
    QString encoderId;
    // Advanced/test hook. Segment boundaries are multiples of 1024 samples.
    int segmentTargetUs = 8'000'000;

    bool operator==(const ExportSettings &) const = default;
};

struct ExportPreset {
    QString id;
    QString name;
    ExportVideoCodec codec = ExportVideoCodec::H264;
    int width = 1920;
    int height = 1080;
    Rational fps{30, 1};
    bool matchTimeline = false;
    ExportQuality quality = ExportQuality::Medium;
    int bitrateKbps = 0;
};

struct ExportTiming {
    int64_t totalFrames = 0;
    int64_t totalSamples = 0;
    int64_t segmentSamples = 0; // always a multiple of 1024
    int segmentCount = 0;
    int sampleRate = 48000;
```

```cpp
int64_t roundDiv(int64_t num, int64_t den)
{
    if (den <= 0)
        return 0;
    return num >= 0 ? (num + den / 2) / den : -((-num + den / 2) / den);
}

int evenDimension(int value)
{
    return std::max(2, (value / 2) * 2);
}

} // namespace

int64_t framePtsUs(int64_t frame, const Rational &fps)
{
    if (!fps.isValid())
        return 0;
    return roundDiv(frame * 1'000'000LL * fps.den, fps.num);
}

int64_t firstVideoFrameAtOrAfter(int64_t timeUs, const Rational &fps)
{
    if (!fps.isValid())
        return 0;
    if (timeUs <= 0)
        return 0;
    // ceil(timeUs * fps.num / (1e6 * fps.den)), then correct for PTS rounding.
    int64_t frame = (timeUs * fps.num + int64_t(fps.den) * 1'000'000LL - 1)
                    / (int64_t(fps.den) * 1'000'000LL);
    while (frame > 0 && framePtsUs(frame - 1, fps) >= timeUs)
        --frame;
    while (framePtsUs(frame, fps) < timeUs)
        ++frame;
    return frame;
}

ExportTiming computeExportTiming(int64_t durationUs, const Rational &fps,
                                 int sampleRate, int segmentTargetUs)
{
    ExportTiming timing;
    timing.sampleRate = sampleRate;
    if (!fps.isValid() || durationUs <= 0 || sampleRate <= 0)
        return timing;
    timing.totalFrames = std::max<int64_t>(
        1, roundDiv(durationUs * fps.num, int64_t(fps.den) * 1'000'000LL));
    timing.totalSamples = std::max<int64_t>(
        1, roundDiv(timing.totalFrames * sampleRate * fps.den, fps.num));

    const int64_t targetSamples = std::max<int64_t>(
        1024, roundDiv(int64_t(segmentTargetUs) * sampleRate, 1'000'000LL));
    const int64_t aacFrames = std::max<int64_t>(1, (targetSamples + 512) / 1024);
    timing.segmentSamples = aacFrames * 1024;
    timing.segmentCount = int(
        (timing.totalSamples + timing.segmentSamples - 1) / timing.segmentSamples);
    return timing;
}

int64_t segmentStartUs(const ExportTiming &timing, int segmentIndex)
{
    return roundDiv(int64_t(segmentIndex) * timing.segmentSamples * 1'000'000LL,
                    timing.sampleRate);
}

void audioSampleRangeForSegment(const ExportTiming &timing, int segmentIndex,
                                int64_t *sampleBegin, int64_t *sampleEnd)
{
    const int64_t begin = int64_t(segmentIndex) * timing.segmentSamples;
    const int64_t end = std::min(timing.totalSamples, begin + timing.segmentSamples);
    if (sampleBegin)
        *sampleBegin = begin;
    if (sampleEnd)
        *sampleEnd = std::max(begin, end);
}

void videoFrameRangeForSegment(const ExportTiming &timing, const Rational &fps,
                               int segmentIndex, int64_t *frameBegin,
                               int64_t *frameEnd)
{
    const int64_t begin =
        firstVideoFrameAtOrAfter(segmentStartUs(timing, segmentIndex), fps);
    int64_t end = timing.totalFrames;
    if (segmentIndex + 1 < timing.segmentCount) {
        end = firstVideoFrameAtOrAfter(segmentStartUs(timing, segmentIndex + 1),
                                       fps);
    }
    end = std::clamp(end, begin, timing.totalFrames);
    if (frameBegin)
        *frameBegin = begin;
    if (frameEnd)
        *frameEnd = end;
}

    path = path.trimmed();

        return path;
    const QFileInfo info(path);
    if (info.suffix().compare(QStringLiteral("mp4"), Qt::CaseInsensitive) != 0)
        path += QStringLiteral(".mp4");
    return path;
}

{
    QFileInfo info(outputPath);
    return info.dir().filePath(info.completeBaseName() + QStringLiteral(".srt"));
}
```

```cpp
bool probeEncoder(const QString &encoderId, ExportVideoCodec codec,
                  bool hardware, int width, int height, const Rational &fps,
                  QString *error)
{
    const QByteArray id = encoderId.toUtf8();
    const AVCodec *codecPtr = avcodec_find_encoder_by_name(id.constData());
    if (!codecPtr) {
        if (error)
            *error = QStringLiteral("当前 FFmpeg 构建不包含编码器 %1。").arg(encoderId);
        return false;
    }
    AVCodecContext *ctx = avcodec_alloc_context3(codecPtr);
    if (!ctx) {
        if (error) *error = QStringLiteral("无法分配编码器上下文。");
        return false;
    }
    ctx->width = width;
    ctx->height = height;
    ctx->time_base = AVRational{fps.den, fps.num};
    ctx->framerate = AVRational{fps.num, fps.den};
    EncoderDescriptor descriptor;
    descriptor.id = encoderId;
    descriptor.codec = codec;
    descriptor.hardware = hardware;
    ctx->pix_fmt = encoderPixelFormat(descriptor);
    ctx->bit_rate = 2'000'000;
    ctx->gop_size = 30;
    ctx->max_b_frames = 0;
    ctx->flags |= AV_CODEC_FLAG_GLOBAL_HEADER;
    applyEncoderOptions(ctx, descriptor);

    int ret = avcodec_open2(ctx, codecPtr, nullptr);
    if (ret < 0) {
        if (error)
            *error = ffmpegErrorString(ret);
        avcodec_free_context(&ctx);
        return false;
    }

    AVFrame *frame = av_frame_alloc();
    frame->format = ctx->pix_fmt;
    frame->width = width;
    frame->height = height;
    ret = av_frame_get_buffer(frame, 0);
    if (ret < 0) {
        if (error) *error = ffmpegErrorString(ret);
        av_frame_free(&frame);
        avcodec_free_context(&ctx);
        return false;
    }
    AVPacket *packet = av_packet_alloc();
    bool gotPacket = false;
    for (int i = 0; i < 3 && !gotPacket; ++i) {
        av_frame_make_writable(frame);
        memset(frame->data[0], 16, size_t(frame->linesize[0]) * height);
        if (frame->data[1])
            memset(frame->data[1], 128,
                   size_t(frame->linesize[1]) * ((height + 1) / 2));
        if (frame->data[2])
            memset(frame->data[2], 128,
                   size_t(frame->linesize[2]) * ((height + 1) / 2));
        frame->pts = i;
        ret = avcodec_send_frame(ctx, frame);
        if (ret < 0) {
            if (error) *error = ffmpegErrorString(ret);
            break;
        }
        ret = avcodec_receive_packet(ctx, packet);
        if (ret == 0) {
            gotPacket = packet->size > 0;
            av_packet_unref(packet);
        } else if (ret != AVERROR(EAGAIN)) {
            if (error) *error = ffmpegErrorString(ret);
            break;
        }
    }
    if (!gotPacket) {
        avcodec_send_frame(ctx, nullptr);
        if (avcodec_receive_packet(ctx, packet) == 0) {
            gotPacket = packet->size > 0;
            av_packet_unref(packet);
        }
    }
    if (!gotPacket && error && error->isEmpty())
        *error = QStringLiteral("编码器无法输出测试帧。");
    av_packet_free(&packet);
    av_frame_free(&frame);
    avcodec_free_context(&ctx);
    return gotPacket;
}
```

```cpp
QString EncoderCatalog::selectEncoder(ExportVideoCodec codec,
                                      bool preferHardware,
                                      bool *hardwareOut, QString *reason) const
{
    if (hardwareOut) *hardwareOut = false;
    if (reason) reason->clear();
    QList<const EncoderDescriptor *> available;
    for (const EncoderDescriptor &encoder : encoders) {
        if (encoder.codec == codec && encoder.available)
            available.append(&encoder);
    }
    if (codec == ExportVideoCodec::H265) {
        for (const EncoderDescriptor *encoder : available) {
            if (encoder->hardware) {
                if (hardwareOut) *hardwareOut = true;
                return encoder->id;
            }
        }
        if (reason) {
            *reason = QStringLiteral(
                "当前系统没有可用的 H.265/HEVC 硬件编码器"
                "（NVENC / Quick Sync / AMF / Media Foundation 均不可用）。"
                "H.265 导出仅支持硬件编码，请改用 H.264。");
        }
        return {};
    }
    auto first = [&available](bool hardware) -> const EncoderDescriptor * {
        for (const EncoderDescriptor *encoder : available) {
            if (encoder->hardware == hardware)
                return encoder;
        }
        return nullptr;
    };
    const EncoderDescriptor *chosen = nullptr;
    if (codec == ExportVideoCodec::H264 && !preferHardware) {
        const QString preferred = preferredSoftwareH264Key();
        for (const EncoderDescriptor *encoder : available) {
            if (!encoder->hardware && encoder->key() == preferred) {
                chosen = encoder;
                break;
            }
        }
        if (!chosen) chosen = first(false);
        if (!chosen) chosen = first(true);
    } else {
        chosen = preferHardware ? first(true) : first(false);
        if (!chosen) chosen = preferHardware ? first(false) : first(true);
    }
    if (!chosen) {
        if (reason)
            *reason = QStringLiteral("没有可用的 %1 编码器。")
                          .arg(exportCodecDisplayName(codec));
        return {};
    }
    if (hardwareOut) *hardwareOut = chosen->hardware;
    return chosen->id;
}
```

```cpp
int TimelineCompositor::drawFrame(int64_t timelineUs,
                                  ID3D11RenderTargetView *target,
                                  bool clearBlack, QString *error)
{
    if (!m_valid || !m_compositor || !target) {
        if (error) *error = QStringLiteral("合成器未初始化。");
        return 0;
    }
    const FrameComposition frame =
        TimelineEvaluator(m_project).frameAt(std::max<int64_t>(0, timelineUs));
    m_compositor->begin(target, clearBlack);
    QSet<QString> usedThisFrame;
    int drawnLayers = 0;
    for (const VideoLayer &layer : frame.video) {
        if (!m_project.assetById(layer.assetId))
            continue;
        ClipVideoSource *source = sourceFor(layer);
        if (!source)
            continue;
        usedThisFrame.insert(layer.clipId);
        QString layerError;
        const DecodedFrame *decoded =
            source->frameAt(layer.sourceTimeUs, &layerError);
        if (!layerError.isEmpty())
            reportOnce(QStringLiteral("decode:") + layer.clipId, layerError);
        if (!decoded)
            continue;
        const LayerRect rect =
            layerRectFor(layer.transform, source->width(), source->height(),
                         m_width, m_height);
        const float opacity =
            std::clamp(layer.transform.opacityMilli / 1000.0f, 0.0f, 1.0f);
        if (m_compositor->drawFrame(*decoded, rect, opacity, &layerError))
            ++drawnLayers;
        else if (!layerError.isEmpty())
            reportOnce(QStringLiteral("draw:") + layer.clipId, layerError);
    }
    QHash<QString, quint64> lastUsed;
    for (const auto &entry : m_sources)
        lastUsed.insert(entry.first, entry.second.lastUsedFrame);
    const QStringList evicted =
        evictSourceKeys(lastUsed, usedThisFrame, kMaxCachedSources);
    for (const QString &clipId : evicted) {
        auto it = m_sources.find(clipId);
        if (it == m_sources.end())
            continue;
        m_compositor->forgetTexture(it->second.source->texture());
        m_sources.erase(it);
    }
    const QImage subtitles = subtitleImageFor(frame.subtitles);
    if (!subtitles.isNull()) {
        QString drawError;
        if (!m_compositor->drawImageCached(m_subtitleKey, subtitles,
                                           LayerRect{0, 0, 1, 1}, 1.0f,
                                           &drawError)
            && !drawError.isEmpty() && m_warning) {
            m_warning(drawError);
        }
    }
    m_compositor->end();
    return drawnLayers;
}
```

```cpp
bool OfflineFrameRenderer::open(const Project &project, int width, int height,
                                QString *error)
{
    close();
    m_width = width;
    m_height = height;
    m_compositor = std::make_unique<TimelineCompositor>();
    m_compositor->setWarningCallback(
        [this](const QString &message) {
            if (m_warning) m_warning(message);
        });
    if (!m_compositor->open(project, width, height, false, error))
        return false;
    return ensureTarget(error);
}

bool OfflineFrameRenderer::ensureTarget(QString *error)
{
    D3D11Context *context = m_compositor->context();
    D3D11_TEXTURE2D_DESC desc{};
    desc.Width = UINT(m_width);
    desc.Height = UINT(m_height);
    desc.MipLevels = 1;
    desc.ArraySize = 1;
    desc.Format = DXGI_FORMAT_R8G8B8A8_UNORM;
    desc.SampleDesc.Count = 1;
    desc.Usage = D3D11_USAGE_DEFAULT;
    desc.BindFlags = D3D11_BIND_RENDER_TARGET | D3D11_BIND_SHADER_RESOURCE;
    if (FAILED(context->device()->CreateTexture2D(&desc, nullptr, &m_target))) {
        if (error) *error = QStringLiteral("无法创建导出合成纹理。");
        return false;
    }
    if (FAILED(context->device()->CreateRenderTargetView(
            m_target.Get(), nullptr, &m_rtv))) {
        if (error) *error = QStringLiteral("无法创建导出渲染目标。");
        return false;
    }
    desc.Usage = D3D11_USAGE_STAGING;
    desc.BindFlags = 0;
    desc.CPUAccessFlags = D3D11_CPU_ACCESS_READ;
    if (FAILED(context->device()->CreateTexture2D(&desc, nullptr, &m_staging))) {
        if (error) *error = QStringLiteral("无法创建导出回读纹理。");
        return false;
    }
    return true;
}

bool OfflineFrameRenderer::renderFrame(int64_t timelineUs,
                                       std::vector<uint8_t> *rgba,
                                       QString *error)
{
    if (!m_compositor || !m_rtv || !rgba)
        return false;
    QString drawError;
    m_compositor->drawFrame(timelineUs, m_rtv.Get(), true, &drawError);
    if (!drawError.isEmpty()) {
        if (error) *error = drawError;
        return false;
    }
    D3D11Context *context = m_compositor->context();
    context->context()->CopyResource(m_staging.Get(), m_target.Get());
    D3D11_MAPPED_SUBRESOURCE mapped{};
    if (FAILED(context->context()->Map(m_staging.Get(), 0, D3D11_MAP_READ, 0,
                                       &mapped))) {
        if (error) *error = QStringLiteral("无法回读导出帧。");
        return false;
    }
    rgba->resize(size_t(m_width) * size_t(m_height) * 4);
    for (int y = 0; y < m_height; ++y) {
        memcpy(rgba->data() + size_t(y) * size_t(m_width) * 4,
               static_cast<const uint8_t *>(mapped.pData)
                   + size_t(y) * mapped.RowPitch,
               size_t(m_width) * 4);
    }
    context->context()->Unmap(m_staging.Get(), 0);
    return true;
}
```

```cpp
bool VideoEncoder::open(const EncoderDescriptor &encoder,
                        const ExportSettings &settings, QString *error)
{
    close();
    if (settings.width <= 0 || settings.height <= 0
        || settings.width % 2 != 0 || settings.height % 2 != 0) {
        if (error) *error = QStringLiteral("视频编码要求偶数宽高。");
        return false;
    }
    const QByteArray id = encoder.id.toUtf8();
    const AVCodec *codec = avcodec_find_encoder_by_name(id.constData());
    if (!codec) {
        if (error)
            *error = QStringLiteral("当前 FFmpeg 构建不包含编码器 %1。").arg(encoder.id);
        return false;
    }
    m_ctx = avcodec_alloc_context3(codec);
    m_ctx->width = settings.width;
    m_ctx->height = settings.height;
    m_ctx->time_base = AVRational{settings.fps.den, settings.fps.num};
    m_ctx->framerate = AVRational{settings.fps.num, settings.fps.den};
    m_ctx->pix_fmt = encoderPixelFormat(encoder);
    m_ctx->bit_rate = int64_t(effectiveBitrateKbps(settings)) * 1000;
    m_ctx->gop_size = std::max(1, int(std::lround(settings.fps.toDouble())));
    m_ctx->max_b_frames = 0;
    m_ctx->flags |= AV_CODEC_FLAG_GLOBAL_HEADER;
    m_ctx->color_range = AVCOL_RANGE_MPEG;
    m_ctx->colorspace = AVCOL_SPC_BT709;
    m_ctx->color_primaries = AVCOL_PRI_BT709;
    m_ctx->color_trc = AVCOL_TRC_BT709;
    applyEncoderOptions(m_ctx, encoder);

    int ret = avcodec_open2(m_ctx, codec, nullptr);
    if (ret < 0) {
        if (error) *error = ffmpegErrorString(ret);
        close();
        return false;
    }
    m_frame = av_frame_alloc();
    m_frame->format = m_ctx->pix_fmt;
    m_frame->width = settings.width;
    m_frame->height = settings.height;
    m_frame->color_range = AVCOL_RANGE_MPEG;
    m_frame->colorspace = AVCOL_SPC_BT709;
    ret = av_frame_get_buffer(m_frame, 0);
    if (ret < 0) {
        if (error) *error = ffmpegErrorString(ret);
        close();
        return false;
    }
    m_packet = av_packet_alloc();
    m_sws = sws_getContext(settings.width, settings.height, AV_PIX_FMT_RGBA,
                           settings.width, settings.height, m_ctx->pix_fmt,
                           SWS_BILINEAR, nullptr, nullptr, nullptr);
    if (!m_sws) {
        if (error) *error = QStringLiteral("无法创建 RGBA 到 YUV 的颜色转换器。");
        close();
        return false;
    }
    sws_setColorspaceDetails(m_sws, sws_getCoefficients(SWS_CS_ITU709), 1,
                             sws_getCoefficients(SWS_CS_ITU709), 0, 0,
                             1 << 16, 1 << 16);
    m_width = settings.width;
    m_height = settings.height;
    m_hardware = encoder.hardware;
    return true;
}
```

```cpp
bool VideoEncoder::receivePackets(std::vector<EncodedPacket> *packets,
                                  QString *error)
{
    while (true) {
        const int ret = avcodec_receive_packet(m_ctx, m_packet);
        if (ret == AVERROR(EAGAIN) || ret == AVERROR_EOF)
            return true;
        if (ret < 0) {
            if (error) *error = ffmpegErrorString(ret);
            return false;
        }
        EncodedPacket packet;
        packet.data.assign(m_packet->data, m_packet->data + m_packet->size);
        packet.pts = m_packet->pts;
        packet.dts = m_packet->dts;
        packet.duration = m_packet->duration;
        packet.key = (m_packet->flags & AV_PKT_FLAG_KEY) != 0;
        packets->push_back(std::move(packet));
        av_packet_unref(m_packet);
    }
}

bool VideoEncoder::flush(std::vector<EncodedPacket> *packets, QString *error)
{
    if (!m_ctx) return true;
    const int ret = avcodec_send_frame(m_ctx, nullptr);
    if (ret < 0 && ret != AVERROR_EOF) {
        if (error) *error = ffmpegErrorString(ret);
        return false;
    }
    return receivePackets(packets, error);
}
```

```cpp
{
    m_startSamples = std::max<int64_t>(0, sampleIndex);
    m_startPositionUs =
        (m_startSamples * 1'000'000LL + m_sampleRate / 2) / m_sampleRate;
    m_framesRendered = 0;
    for (auto &entry : m_readers) {
        if (entry.second.reader)
            entry.second.reader->reset();
    }
}

int64_t TimelineMixer::positionSamples() const
{
    if (m_startSamples >= 0)
        return m_startSamples + m_framesRendered;
    return (m_startPositionUs * m_sampleRate + 500'000LL) / 1'000'000LL
           + m_framesRendered;
}

void TimelineMixer::setPosition(int64_t positionUs)
{
    m_startSamples = -1;
    m_startPositionUs = std::max<int64_t>(0, positionUs);
    m_framesRendered = 0;
    for (auto &entry : m_readers) {
        if (entry.second.reader)
            entry.second.reader->reset();
    }
}

int64_t TimelineMixer::positionForFrameCount(int64_t frames) const
{
    if (m_startSamples >= 0) {
        return ((m_startSamples + frames) * 1'000'000LL + m_sampleRate / 2)
               / m_sampleRate;
    }
    return m_startPositionUs
           + (frames * 1'000'000LL + m_sampleRate / 2) / m_sampleRate;
}
```

```cpp
                        QString *error)
{
    close();
    const AVCodec *codec = avcodec_find_encoder_by_name("aac");
    if (!codec) {
        if (error) *error = QStringLiteral("当前 FFmpeg 构建不包含 AAC 编码器。");
        return false;
    }
    m_ctx = avcodec_alloc_context3(codec);
    m_ctx->sample_fmt = AV_SAMPLE_FMT_FLTP;
    m_ctx->sample_rate = sampleRate;
    av_channel_layout_default(&m_ctx->ch_layout, channels);
    m_ctx->bit_rate = int64_t(bitrateKbps) * 1000;
    m_ctx->profile = AV_PROFILE_AAC_LOW;
    m_ctx->time_base = AVRational{1, sampleRate};
    m_ctx->flags |= AV_CODEC_FLAG_GLOBAL_HEADER;
    int ret = avcodec_open2(m_ctx, codec, nullptr);
    if (ret < 0) {
        if (error) *error = ffmpegErrorString(ret);
        close();
        return false;
    }
    m_frame = av_frame_alloc();
    m_frame->format = AV_SAMPLE_FMT_FLTP;
    m_frame->sample_rate = sampleRate;
    av_channel_layout_copy(&m_frame->ch_layout, &m_ctx->ch_layout);
    m_frame->nb_samples = m_ctx->frame_size > 0 ? m_ctx->frame_size : 1024;
    ret = av_frame_get_buffer(m_frame, 0);
    if (ret < 0) {
        if (error) *error = ffmpegErrorString(ret);
        close();
        return false;
    }
    m_packet = av_packet_alloc();
    m_channels = channels;
    m_delay = m_ctx->initial_padding;
    return true;
}
```

```cpp
bool AudioTrackWriter::write(const EncodedPacket &packet, QString *error)
{
    if (!m_ok || packet.data.empty())
        return false;
    av_new_packet(m_packet, int(packet.data.size()));
    memcpy(m_packet->data, packet.data.data(), packet.data.size());
    m_packet->pts = packet.pts;
    m_packet->dts = packet.pts;
    m_packet->duration = packet.duration > 0 ? packet.duration : 1024;
    m_packet->stream_index = m_stream->index;
    av_packet_rescale_ts(m_packet, AVRational{1, m_sampleRate},
                         m_stream->time_base);
    const int ret = av_interleaved_write_frame(m_oc, m_packet);
    av_packet_unref(m_packet);
    if (ret < 0) {
        if (error) *error = ffmpegErrorString(ret);
        m_ok = false;
        return false;
    }
    return true;
}

bool AudioTrackWriter::finish(QString *error)
{
    if (!m_oc)
        return false;
    const bool wasOk = m_ok;
    int ret = 0;
    if (wasOk)
        ret = av_write_trailer(m_oc);
    avio_closep(&m_oc->pb);
    avformat_free_context(m_oc);
    m_oc = nullptr;
    av_packet_free(&m_packet);
    m_ok = false;
    if (!wasOk)
        return false;
    if (ret < 0) {
        if (error) *error = ffmpegErrorString(ret);
        return false;
    }
    return true;
}
```

路由规则：视频 packet 的 `pts` 是全局帧号；找到满足 `frameBegin(i) <= pts < frameEnd(i)` 的 `i`。游标只增不减（编码器按 PTS 单调输出）；若 packet 落在已关闭分段或游标回退，返回错误“编码器输出顺序异常”。`ensureWriter(i)` 用 `videoFrameRangeForSegment` 取 `rebaseFrame`。`closeThrough(i)` 关闭所有 `<= i` 的分段，关闭前核对：

```cpp
int64_t vBegin = 0, vEnd = 0;
videoFrameRangeForSegment(m_timing, m_fps, s, &vBegin, &vEnd);
const int64_t expectedVideo = vEnd - vBegin;
if (writer->videoPackets() != expectedVideo) {
    if (error) *error = QStringLiteral(
        "分段 %1 的编码包数量与时间线不一致（视频 %2/%3）。")
        .arg(s).arg(writer->videoPackets()).arg(expectedVideo);
    return false;
}
```

`finishAll(allowPartialLastSegment, error)`：调用方已把编码器尾部 packet 路由完。对每个仍打开的 writer，若是最后一段且 `allowPartialLastSegment` 为真，按该段实际帧范围（`vEnd-vBegin`）校验 packet 数，数量不足则返回错误，满足则计入完成数；否则（取消/失败）调用 `finish()` 关闭后删除该分段文件、不计入完成数。返回时 `completedSegments()` 只包含已经 `closeThrough` 或成功 `finishAll(true)` 校验通过的分段。保持最多 4 个 writer 打开：每次 `routeVideo` 成功后，若 `maxOpen > 4`，调用 `closeThrough(m_videoCursor - 3)`。由于编码器延迟远小于一个 8 秒分段，安全。

```cpp
bool Mp4Assembler::assemble(const QString &partsDir, const QString &audioPartPath,
                            const ExportTiming &timing, const Rational &fps,
                            AVCodecContext *video, AVCodecContext *audio,
                            int64_t audioDelay, int64_t paddedSamples,
                            const QString &tempOutput, QString *error)
{
    AVFormatContext *out = nullptr;
    if (avformat_alloc_output_context2(&out, nullptr, "mp4",
                                       tempOutput.toUtf8().constData()) < 0 || !out) {
        if (error) *error = QStringLiteral("无法创建最终 MP4 封装器。");
        return false;
    }
    AVStream *outVideo = avformat_new_stream(out, nullptr);
    AVStream *outAudio = avformat_new_stream(out, nullptr);
    outVideo->time_base = AVRational{fps.den, fps.num};
    outAudio->time_base = AVRational{1, timing.sampleRate};
    outVideo->avg_frame_rate = AVRational{fps.num, fps.den};
    avcodec_parameters_from_context(outVideo->codecpar, video);
    avcodec_parameters_from_context(outAudio->codecpar, audio);
    if (video->codec_id == AV_CODEC_ID_HEVC)
        outVideo->codecpar->codec_tag = MKTAG('h', 'v', 'c', '1');
    outVideo->duration = timing.totalFrames;
    outAudio->duration = timing.totalSamples;
    if (avio_open(&out->pb, tempOutput.toUtf8().constData(), AVIO_FLAG_WRITE) < 0) {
        if (error) *error = QStringLiteral("无法创建最终 MP4 文件。");
        return false;
    }
    AVDictionary *options = nullptr;
    av_dict_set(&options, "movflags", "+faststart", 0);
    int ret = avformat_write_header(out, &options);
    av_dict_free(&options);
    if (ret < 0) {
        if (error) *error = ffmpegErrorString(ret);
        return false;
    }

    // All video segments must share the same SPS/PPS as the encoder context.
    std::vector<uint8_t> referenceExtradata;
    for (int i = 0; i < timing.segmentCount; ++i) {
        AVFormatContext *in = nullptr;
        const QString path = segmentPath(partsDir, i);
        if (avformat_open_input(&in, path.toUtf8().constData(), nullptr,
                                nullptr) < 0) {
            if (error) *error = QStringLiteral("无法读取分段：%1").arg(path);
            return false;
        }
        const int vi = av_find_best_stream(in, AVMEDIA_TYPE_VIDEO, -1, -1,
                                           nullptr, 0);
        if (vi < 0) {
            if (error) *error = QStringLiteral("分段缺少视频流：%1").arg(path);
            avformat_close_input(&in);
            return false;
        }
        AVStream *v = in->streams[vi];
        if (i == 0) {
            referenceExtradata.assign(v->codecpar->extradata,
                                      v->codecpar->extradata
                                          + v->codecpar->extradata_size);
        } else if (referenceExtradata.size()
                       != size_t(v->codecpar->extradata_size)
                   || memcmp(referenceExtradata.data(), v->codecpar->extradata,
                             referenceExtradata.size()) != 0) {
            if (error) *error = QStringLiteral(
                "分段编码参数不一致（SPS/PPS 不同），无法合并为单个 MP4。");
            avformat_close_input(&in);
            return false;
        }
        avformat_close_input(&in);
    }

    // 1) 视频：每个分段单独读取 packet，按精确全局帧偏移重写。
    for (int i = 0; i < timing.segmentCount; ++i) {
        AVFormatContext *in = nullptr;
        const QString path = segmentPath(partsDir, i);
        if (avformat_open_input(&in, path.toUtf8().constData(), nullptr, nullptr) < 0) {
            if (error) *error = QStringLiteral("无法读取分段：%1").arg(path);
            return false;
        }
        const int vi = av_find_best_stream(in, AVMEDIA_TYPE_VIDEO, -1, -1, nullptr, 0);
        if (vi < 0) {
            if (error) *error = QStringLiteral("分段缺少视频流：%1").arg(path);
            avformat_close_input(&in);
            return false;
        }
        int64_t vBegin = 0, vEnd = 0;
        videoFrameRangeForSegment(timing, fps, i, &vBegin, &vEnd);
        AVPacket *pkt = av_packet_alloc();
        while (av_read_frame(in, pkt) >= 0) {
            if (pkt->stream_index != vi) {
                av_packet_unref(pkt);
                continue;
            }
            av_packet_rescale_ts(pkt, in->streams[vi]->time_base,
                                 outVideo->time_base);
            pkt->pts += av_rescale_q(vBegin, AVRational{fps.den, fps.num},
                                     outVideo->time_base);
            pkt->dts = pkt->pts;
            pkt->duration = 1;
            pkt->stream_index = outVideo->index;
            ret = av_interleaved_write_frame(out, pkt);
            av_packet_unref(pkt);
            if (ret < 0) {
                if (error) *error = ffmpegErrorString(ret);
                av_packet_free(&pkt);
                avformat_close_input(&in);
                av_write_trailer(out);
                return false;
            }
        }
        av_packet_free(&pkt);
        avformat_close_input(&in);
    }

    // 2) 音频：单个连续音频分段，PTS 从 0 开始，不需要分段偏移。
    AVFormatContext *audioIn = nullptr;
    if (avformat_open_input(&audioIn, audioPartPath.toUtf8().constData(),
                            nullptr, nullptr) < 0) {
        if (error)
            *error = QStringLiteral("无法读取音频分段：%1").arg(audioPartPath);
        av_write_trailer(out);
        return false;
    }
    const int ai = av_find_best_stream(audioIn, AVMEDIA_TYPE_AUDIO, -1, -1,
                                       nullptr, 0);
    if (ai < 0) {
        if (error) *error = QStringLiteral("音频分段缺少音频流。");
        avformat_close_input(&audioIn);
        av_write_trailer(out);
        return false;
    }
    AVPacket *apkt = av_packet_alloc();
    bool firstAudioPacket = true;
    while (av_read_frame(audioIn, apkt) >= 0) {
        if (apkt->stream_index != ai) {
            av_packet_unref(apkt);
            continue;
        }
        av_packet_rescale_ts(apkt, audioIn->streams[ai]->time_base,
                             outAudio->time_base);
        apkt->stream_index = outAudio->index;
        apkt->dts = apkt->pts;
        if (firstAudioPacket && audioDelay > 0) {
            uint8_t *side = av_packet_new_side_data(
                apkt, AV_PKT_DATA_SKIP_SAMPLES, 8);
            if (side) {
                AV_WL32(side, uint32_t(audioDelay));
                AV_WL32(side + 4, 0);
            }
            firstAudioPacket = false;
        }
        if (paddedSamples > 0
            && apkt->pts + apkt->duration
                   >= av_rescale_q(timing.totalSamples,
                                   AVRational{1, timing.sampleRate},
                                   outAudio->time_base)) {
            uint8_t *side = av_packet_new_side_data(
                apkt, AV_PKT_DATA_SKIP_SAMPLES, 8);
            if (side) {
                AV_WL32(side, 0);
                AV_WL32(side + 4, uint32_t(paddedSamples));
            }
        }
        ret = av_interleaved_write_frame(out, apkt);
        av_packet_unref(apkt);
        if (ret < 0) {
            if (error) *error = ffmpegErrorString(ret);
            av_packet_free(&apkt);
            avformat_close_input(&audioIn);
            av_write_trailer(out);
            return false;
        }
    }
    av_packet_free(&apkt);
    avformat_close_input(&audioIn);
    ret = av_write_trailer(out);
    avio_closep(&out->pb);
    avformat_free_context(out);
    if (ret < 0) {
        if (error) *error = ffmpegErrorString(ret);
        return false;
    }
    return true;
}
```

```cpp
qint64 estimateExportBytes(const ExportSettings &settings,
                           const ExportTiming &timing)
{
    const int64_t durationUs =
        (timing.totalFrames * 1'000'000LL * settings.fps.den
         + settings.fps.num / 2) / settings.fps.num;
    const int64_t videoBytes =
        int64_t(effectiveBitrateKbps(settings)) * 1000 / 8 * durationUs
        / 1'000'000LL;
    const int64_t audioBytes = int64_t(192'000 / 8) * durationUs / 1'000'000LL;
    const int64_t overhead = (videoBytes + audioBytes) / 10;
    return std::max<qint64>(256LL << 20,
                            videoBytes + audioBytes + overhead + (64LL << 20));
}

DiskSpaceEstimate evaluateDiskSpace(qint64 freeBytes, qint64 requiredBytes)
{
    DiskSpaceEstimate result;
    result.freeBytes = freeBytes;
    result.requiredBytes = requiredBytes;
    result.ok = freeBytes >= requiredBytes;
    if (!result.ok) {
        result.error = QStringLiteral(
            "磁盘空间不足：导出至少需要 %1，当前可用 %2。请清理磁盘或更换输出位置。")
            .arg(formatBytes(requiredBytes), formatBytes(freeBytes));
    }
    return result;
}
```

```cpp
ExportValidation validateExportFile(const QString &path,
                                    const ExportSettings &settings,
                                    const ExportTiming &timing)
{
    ExportValidation v;
    QString error;
    const auto info = MediaProbe::probe(path, &error);
    if (!info) { v.error = error; return v; }
    v.info = *info;
    const int64_t frameUs =
        (1'000'000LL * settings.fps.den + settings.fps.num / 2)
        / settings.fps.num;
    if (info->container != QStringLiteral("MP4")) {
        v.error = QStringLiteral("导出文件不是 MP4 容器。");
        return v;
    }
    if (info->videoCodec != exportCodecFfmpegName(settings.codec)) {
        v.error = QStringLiteral("视频编码不匹配：期望 %1，实际 %2。")
                      .arg(exportCodecFfmpegName(settings.codec), info->videoCodec);
        return v;
    }
    if (info->width != settings.width || info->height != settings.height) {
        v.error = QStringLiteral("分辨率不匹配：期望 %1×%2，实际 %3×%4。")
                      .arg(settings.width).arg(settings.height)
                      .arg(info->width).arg(info->height);
        return v;
    }
    if (!info->hasAudio || info->audioCodec != QStringLiteral("aac")
        || info->audioSampleRate != 48'000 || info->audioChannels != 2) {
        v.error = QStringLiteral("音频轨不符合要求（需要 AAC、48 kHz、双声道）。");
        return v;
    }
    const double expectedFps = settings.fps.toDouble();
    if (!info->frameRate.isValid()
        || std::abs(info->frameRate.toDouble() - expectedFps) > 0.01) {
        v.error = QStringLiteral("帧率不匹配。");
        return v;
    }
    // 遍历 packet 统计视频帧数与音频采样数，并解码首个视频 packet。
    AVFormatContext *in = nullptr;
    if (avformat_open_input(&in, path.toUtf8().constData(), nullptr, nullptr) < 0) {
        v.error = QStringLiteral("无法重新打开导出文件。");
        return v;
    }
    const int vi = av_find_best_stream(in, AVMEDIA_TYPE_VIDEO, -1, -1, nullptr, 0);
    const int ai = av_find_best_stream(in, AVMEDIA_TYPE_AUDIO, -1, -1, nullptr, 0);
    AVPacket *pkt = av_packet_alloc();
    AVPacket *firstVideo = nullptr;
    while (av_read_frame(in, pkt) >= 0) {
        if (pkt->stream_index == vi) {
            ++v.videoPacketCount;
            if (!firstVideo) {
                firstVideo = av_packet_alloc();
                av_packet_ref(firstVideo, pkt);
            }
        } else if (pkt->stream_index == ai) {
            v.audioSampleCount += av_rescale_q(
                pkt->duration, in->streams[ai]->time_base,
                AVRational{1, 48000});
        }
        av_packet_unref(pkt);
    }
    const int64_t expectedVideoUs =
        (timing.totalFrames * 1'000'000LL * settings.fps.den
         + settings.fps.num / 2) / settings.fps.num;
    const int64_t expectedAudioUs =
        (timing.totalSamples * 1'000'000LL + 24'000) / 48'000;
    v.videoDurationUs = info->durationUs;
    v.audioDurationUs = info->audioDurationUs;
    if (std::llabs(v.videoDurationUs - expectedVideoUs) > frameUs + 1) {
        v.error = QStringLiteral("视频时长偏差超过一帧。");
    } else if (std::llabs(v.audioDurationUs - expectedAudioUs) > frameUs + 1) {
        v.error = QStringLiteral("音频时长偏差超过一帧。");
    } else if (std::llabs(v.audioDurationUs - v.videoDurationUs) > frameUs + 1) {
        v.error = QStringLiteral("音画时长偏差超过一帧。");
    } else if (v.videoPacketCount != timing.totalFrames) {
        v.error = QStringLiteral("视频帧数不匹配：期望 %1，实际 %2。")
                      .arg(timing.totalFrames).arg(v.videoPacketCount);
    } else if (std::llabs(v.audioSampleCount - timing.totalSamples) > 1024) {
        v.error = QStringLiteral("音频采样数偏差超过一个 AAC 帧。");
    } else {
        // 用软件解码器直接解首个 key packet，证明文件可解码。
        v.decodedFirstFrame = decodeFirstPacket(in->streams[vi], firstVideo, &error);
        if (!v.decodedFirstFrame)
            v.error = QStringLiteral("无法解码导出文件的首帧：%1").arg(error);
    }
    av_packet_free(&firstVideo);
    av_packet_free(&pkt);
    avformat_close_input(&in);
    v.ok = v.error.isEmpty();
    return v;
}
```

```cpp
static bool decodeFirstPacket(AVStream *stream, const AVPacket *packet,
                              QString *error)
{
    if (!stream || !packet)
        return false;
    const AVCodec *codec = avcodec_find_decoder(stream->codecpar->codec_id);
    if (!codec) {
        if (error) *error = QStringLiteral("找不到对应的解码器。");
        return false;
    }
    AVCodecContext *ctx = avcodec_alloc_context3(codec);
    if (!ctx || avcodec_parameters_to_context(ctx, stream->codecpar) < 0
        || avcodec_open2(ctx, codec, nullptr) < 0) {
        if (error) *error = QStringLiteral("无法打开解码器。");
        avcodec_free_context(&ctx);
        return false;
    }
    AVFrame *frame = av_frame_alloc();
    int ret = avcodec_send_packet(ctx, packet);
    if (ret >= 0)
        ret = avcodec_receive_frame(ctx, frame);
    const bool ok = ret == 0;
    if (!ok && error)
        *error = ffmpegErrorString(ret);
    av_frame_free(&frame);
    avcodec_free_context(&ctx);
    return ok;
}
```

`run` 的固定顺序：

```cpp
ExportResult ExportPipeline::run(const Project &project,
                                 const ExportSettings &settings,
                                 const EncoderCatalog &catalog, bool resume,
                                 const Hooks &hooks)
{
    ExportResult result;
    result.outputPath = normalizedOutputPath(settings.outputPath);
    ExportSettings frozenSettings = settings;
    frozenSettings.outputPath = result.outputPath;
    QString error;

    const QString validationError =
        validateExportSettings(frozenSettings, project.timeline);
    if (!validationError.isEmpty()) {
        result.error = validationError;
        return result;
    }
    const int64_t durationUs = TimelineEvaluator(project).durationUs();
    if (durationUs <= 0) {
        result.error = QStringLiteral("工程时间线为空，无法导出。");
        return result;
    }
    const ExportTiming timing = computeExportTiming(
        durationUs, frozenSettings.fps, 48000, frozenSettings.segmentTargetUs);

    bool hardware = false;
    QString reason;
    QString encoderId;
    if (!frozenSettings.encoderId.isEmpty()) {
        const EncoderDescriptor *descriptor =
            catalog.findByKey(frozenSettings.encoderId);
        // encoderId 既接受 key，也接受 ffmpeg 名称；找不到时回退自动选择。
        if (!descriptor) {
            for (const EncoderDescriptor &candidate : catalog.encoders) {
                if (candidate.id == frozenSettings.encoderId
                    && candidate.available) {
                    descriptor = &candidate;
                    break;
                }
            }
        }
        if (descriptor && descriptor->available) {
            encoderId = descriptor->id;
            hardware = descriptor->hardware;
        }
    }
    if (encoderId.isEmpty()) {
        encoderId = catalog.selectEncoder(frozenSettings.codec,
                                          frozenSettings.preferHardware,
                                          &hardware, &reason);
    }
    if (encoderId.isEmpty()) {
        result.error = reason;
        return result;
    }
    const EncoderDescriptor *selected = nullptr;
    for (const EncoderDescriptor &candidate : catalog.encoders) {
        if (candidate.id == encoderId && candidate.hardware == hardware
            && candidate.available) {
            selected = &candidate;
            break;
        }
    }
    if (!selected) {
        result.error = QStringLiteral("编码器 %1 不可用。").arg(encoderId);
        return result;
    }
    result.encoderId = selected->key();
    result.usedHardware = hardware;
    if (frozenSettings.codec == ExportVideoCodec::H264 && !hardware
        && frozenSettings.preferHardware) {
        result.warning = QStringLiteral(
            "未找到可用的 H.264 硬件编码器，已使用软件编码（速度较慢）。");
    }

    Project frozen = project;
    // Keep subtitle cues in `frozen` so the SRT sidecar still works when
    // burn-in is off; only the render snapshot hides them.
    Project renderProject = frozen;
    if (!frozenSettings.burnSubtitles) {
        for (Track &track : renderProject.tracks) {
            if (track.type == TrackType::Subtitle)
                track.enabled = false;
        }
    }
    int orphanClipCount = 0;
    for (const Track &track : frozen.tracks) {
        for (const Clip &clip : track.clips) {
            if (!frozen.assetById(clip.assetId))
                ++orphanClipCount;
        }
    }

    const QString outputDir = QFileInfo(result.outputPath).absolutePath();
    if (!QDir().mkpath(outputDir)) {
        result.error = QStringLiteral("无法创建输出目录：%1").arg(outputDir);
        return result;
    }
    const qint64 required = estimateExportBytes(frozenSettings, timing);
    ExportPipeline::FreeBytesFn freeBytes = hooks.freeBytes;
    if (!freeBytes) {
        freeBytes = [](const QString &path) {
            return availableBytesFor(path);
        };
    }
    auto space = evaluateDiskSpace(freeBytes(outputDir), required);
    if (!space.ok) {
        result.error = space.error;
        return result;
    }

    const QString partsDir = partsDirectoryFor(result.outputPath);
    const QString checkpointPath =
        QDir(partsDir).filePath(QStringLiteral("checkpoint.json"));
    const QString hash = exportProjectHash(frozen, frozenSettings);
    ExportCheckpoint checkpoint;
    checkpoint.version = ExportCheckpoint::kVersion;
    checkpoint.projectHash = hash;
    checkpoint.encoderKey = selected->key();
    checkpoint.width = frozenSettings.width;
    checkpoint.height = frozenSettings.height;
    checkpoint.fps = frozenSettings.fps;
    checkpoint.sampleRate = 48000;
    checkpoint.totalFrames = timing.totalFrames;
    checkpoint.totalSamples = timing.totalSamples;
    checkpoint.segmentSamples = timing.segmentSamples;
    checkpoint.segmentCount = timing.segmentCount;
    checkpoint.completedSegments = 0;
    int startSegment = 0;
    if (resume) {
        const auto loaded = ExportCheckpoint::load(checkpointPath, &error);
        if (loaded && loaded->projectHash == hash
            && loaded->encoderKey == selected->key()
            && loaded->totalFrames == timing.totalFrames
            && loaded->totalSamples == timing.totalSamples
            && loaded->segmentSamples == timing.segmentSamples
            && loaded->width == frozenSettings.width
            && loaded->height == frozenSettings.height
            && loaded->fps == frozenSettings.fps) {
            checkpoint = *loaded;
            checkpoint.version = ExportCheckpoint::kVersion;
            startSegment = std::min(checkpoint.completedSegments,
                                    timing.segmentCount);
            // A checkpoint is a claim, not proof: verify every claimed segment
            // and fall back to the first segment whose content does not match.
            for (int i = 0; i < startSegment; ++i) {
                SegmentCounts counts;
                int64_t vBegin = 0, vEnd = 0;
                videoFrameRangeForSegment(timing, frozenSettings.fps, i,
                                          &vBegin, &vEnd);
                if (!inspectSegment(segmentPath(partsDir, i), &counts, &error)
                    || counts.videoPackets != vEnd - vBegin) {
                    startSegment = i;
                    break;
                }
            }
            for (int i = startSegment; i < timing.segmentCount; ++i)
                QFile::remove(segmentPath(partsDir, i));
            result.resumed = startSegment > 0;
            checkpoint.completedSegments = startSegment;
        } else {
            clearParts(partsDir);
        }
    } else {
        clearParts(partsDir);
    }
    if (!QDir().mkpath(partsDir)) {
        result.error = QStringLiteral("无法创建导出临时目录：%1").arg(partsDir);
        return result;
    }

    // SRT 边车在渲染前原子写入；失败则中止，避免“视频成功但字幕丢失”。
    if (frozenSettings.writeSrt) {
        const QString srtPath = frozenSettings.srtPath.isEmpty()
            ? defaultSrtPathFor(result.outputPath) : frozenSettings.srtPath;
        QList<SubtitleCue> cues;
        for (const Track &track : frozen.tracks) {
            if (track.type == TrackType::Subtitle && track.enabled)
                cues.append(track.cues);
        }
        std::sort(cues.begin(), cues.end(),
                  [](const SubtitleCue &a, const SubtitleCue &b) {
                      return a.startUs < b.startUs;
                  });
        const QByteArray srtBytes = writeSrt(cues);
        QSaveFile srt(srtPath);
        if (!srt.open(QIODevice::WriteOnly)
            || srt.write(srtBytes) != srtBytes.size() || !srt.commit()) {
            result.error = QStringLiteral("无法写入 SRT 字幕文件：%1").arg(srtPath);
            return result;
        }
    }

    if (!checkpoint.save(checkpointPath, &error)) {
        result.error = error;
        return result;
    }

    VideoEncoder videoEncoder;
    AudioEncoder audioEncoder;
    OfflineFrameRenderer renderer;
    QStringList warnings;
    if (!videoEncoder.open(*selected, frozenSettings, &error)
        || !audioEncoder.open(48000, 2, 192, &error)
        || !renderer.open(renderProject, frozenSettings.width,
                          frozenSettings.height, &error)) {
        result.error = error;
        return result;
    }
    renderer.setWarningCallback(
        [&warnings](const QString &message) {
            if (!warnings.contains(message)) warnings.append(message);
        });

    SegmentRouter router(partsDir, timing, frozenSettings.fps,
                         videoEncoder.context());
    TimelineMixer mixer(48000, 2);
    mixer.setProject(frozen);
    float peak = 0.0f;
    const int64_t startedMs = QDateTime::currentMSecsSinceEpoch();
    bool canceled = false;
    // Declared before the progress lambda because the lambda reads them.
    int64_t encodedFrames = 0;
    int64_t fedSamples = 0; // audio always starts at sample 0, even on resume
    int64_t paddedSamples = 0;
    if (startSegment < timing.segmentCount) {
        int64_t vBegin = 0, vEnd = 0;
        videoFrameRangeForSegment(timing, frozenSettings.fps, startSegment,
                                  &vBegin, &vEnd);
        encodedFrames = vBegin;
    }
    int currentSegmentFramesDone = 0;
    int currentSegmentFrameCount = 1;

    const auto report = [&](ExportStage stage) {
        if (!hooks.onProgress) return;
        ExportProgress progress;
        progress.stage = stage;
        progress.completedFrames = std::min<int64_t>(encodedFrames,
                                                     timing.totalFrames);
        progress.totalFrames = timing.totalFrames;
        progress.completedSegments = std::min(
            timing.segmentCount, startSegment + router.completedSegments());
        progress.totalSegments = timing.segmentCount;
        if (stage == ExportStage::Rendering) {
            const double withinSegment =
                double(std::clamp(currentSegmentFramesDone, 0,
                                  currentSegmentFrameCount))
                / double(std::max(1, currentSegmentFrameCount));
            const double done = double(progress.completedSegments)
                                + withinSegment;
            progress.percent = int(std::clamp(
                5.0 + 85.0 * done / double(std::max(1, timing.segmentCount)),
                5.0, 90.0));
        } else {
            progress.percent = stage == ExportStage::Preparing ? 2
                : stage == ExportStage::EncodingAudio ? 3
                : stage == ExportStage::Finalizing ? 92
                : stage == ExportStage::Validating ? 96
                : stage == ExportStage::Done ? 100
                : 0;
        }
        progress.elapsedMs = QDateTime::currentMSecsSinceEpoch() - startedMs;
        progress.encodeFps = progress.elapsedMs > 0
            ? double(encodedFrames) * 1000.0 / double(progress.elapsedMs)
            : 0.0;
        progress.etaMs = progress.encodeFps > 0.0
            ? int64_t(double(timing.totalFrames - encodedFrames)
                      * 1000.0 / progress.encodeFps)
            : -1;
        progress.outputBytes = router.bytesWritten();
        progress.resumed = result.resumed;
        hooks.onProgress(progress);
    };
    std::vector<float> mixBlock(480 * 2, 0.0f);
    std::vector<float> aacBlock(1024 * 2, 0.0f);
    int aacFill = 0;

    // Audio pass: always from sample 0, even on resume. This keeps one AAC
    // encoder delay at the start of the file and avoids inserting 1024 priming
    // samples at every resume boundary. Audio encoding is far cheaper than
    // video rendering, so redoing it is acceptable.
    const QString audioPartPath =
        QDir(partsDir).filePath(QStringLiteral("audio.mp4"));
    QFile::remove(audioPartPath);
    AudioTrackWriter audioTrack;
    if (!audioTrack.open(audioPartPath, 48000, audioEncoder.context(),
                         timing.totalSamples, &error)) {
        result.error = error;
        return result;
    }
    mixer.setPositionSamples(0);
    for (int64_t sample = 0; sample < timing.totalSamples; sample += 480) {
        if (hooks.isCanceled && hooks.isCanceled()) { canceled = true; break; }
        const int frames =
            int(std::min<int64_t>(480, timing.totalSamples - sample));
        MixStats stats;
        mixer.render(mixBlock.data(), frames, &stats);
        peak = std::max(peak, stats.peak);
        for (int i = 0; i < frames; ++i) {
            aacBlock[size_t(aacFill) * 2] = mixBlock[size_t(i) * 2];
            aacBlock[size_t(aacFill) * 2 + 1] = mixBlock[size_t(i) * 2 + 1];
            if (++aacFill == 1024) {
                std::vector<EncodedPacket> packets;
                if (!audioEncoder.encode(aacBlock.data(), 1024, fedSamples,
                                         &packets, &error)) {
                    result.error = QStringLiteral("音频编码失败：%1").arg(error);
                    break;
                }
                for (const EncodedPacket &packet : packets) {
                    if (!audioTrack.write(packet, &error)) {
                        result.error = QStringLiteral("音频写入失败：%1").arg(error);
                        break;
                    }
                }
                fedSamples += 1024;
                aacFill = 0;
            }
        }
        if (canceled || !result.error.isEmpty()) break;
        if (sample % (480 * 100) == 0) report(ExportStage::EncodingAudio);
    }
    if (!canceled && result.error.isEmpty()) {
        if (aacFill > 0) {
            std::fill(aacBlock.begin() + aacFill * 2, aacBlock.end(), 0.0f);
            paddedSamples = 1024 - aacFill;
            std::vector<EncodedPacket> packets;
            if (!audioEncoder.encode(aacBlock.data(), 1024, fedSamples,
                                     &packets, &error)) {
                result.error = QStringLiteral("音频尾帧编码失败：%1").arg(error);
            } else {
                for (const EncodedPacket &packet : packets) {
                    if (!audioTrack.write(packet, &error)) {
                        result.error = QStringLiteral("音频写入失败：%1").arg(error);
                        break;
                    }
                }
                fedSamples += 1024;
            }
        }
        std::vector<EncodedPacket> audioTail;
        if (result.error.isEmpty()
            && !audioEncoder.flush(&audioTail, &error)) {
            result.error = error;
        }
        for (const EncodedPacket &packet : audioTail) {
            if (!audioTrack.write(packet, &error)) {
                result.error = QStringLiteral("音频写入失败：%1").arg(error);
                break;
            }
        }
        if (result.error.isEmpty() && !audioTrack.finish(&error))
            result.error = error;
    }
    if (canceled || !result.error.isEmpty()) {
        audioTrack.finish(nullptr);
        QFile::remove(audioPartPath);
        checkpoint.lastError = result.error;
        checkpoint.save(checkpointPath, nullptr);
        result.canceled = canceled;
        result.resumable = checkpoint.completedSegments > 0;
        result.audioPeak = peak;
        return result;
    }

    for (int segment = startSegment; segment < timing.segmentCount; ++segment) {
        if (hooks.isCanceled && hooks.isCanceled()) { canceled = true; break; }
        if (hooks.failAtSegment == segment) {
            result.error = QStringLiteral("模拟分段写入失败（测试注入）。");
            break;
        }
        // Re-check free space before every segment: an export can fill the disk
        // long after start. Keep completed segments and the checkpoint.
        const double remainingFraction =
            double(timing.segmentCount - segment) / double(timing.segmentCount);
        space = evaluateDiskSpace(
            freeBytes(outputDir),
            std::max<qint64>(64LL << 20,
                             qint64(double(required) * remainingFraction)));
        if (!space.ok) {
            result.error = space.error;
            break;
        }
        int64_t vBegin = 0, vEnd = 0;
        videoFrameRangeForSegment(timing, frozenSettings.fps, segment,
                                  &vBegin, &vEnd);
        currentSegmentFrameCount = int(std::max<int64_t>(1, vEnd - vBegin));
        currentSegmentFramesDone = 0;

        for (int64_t frame = vBegin; frame < vEnd; ++frame) {
            if (hooks.isCanceled && hooks.isCanceled()) { canceled = true; break; }
            const int64_t ptsUs = framePtsUs(frame, frozenSettings.fps);
            std::vector<uint8_t> rgba;
            if (!renderer.renderFrame(ptsUs, &rgba, &error)) {
                result.error = QStringLiteral("第 %1 帧渲染失败：%2")
                                   .arg(frame).arg(error);
                break;
            }
            std::vector<EncodedPacket> packets;
            if (!videoEncoder.encodeRgba(rgba.data(), frame, frame == vBegin,
                                         &packets, &error)) {
                result.error = QStringLiteral("第 %1 帧编码失败：%2")
                                   .arg(frame).arg(error);
                break;
            }
            for (const EncodedPacket &packet : packets) {
                if (!router.routeVideo(packet, &error)) {
                    result.error = error;
                    break;
                }
            }
            if (!result.error.isEmpty()) break;
            ++encodedFrames;
            ++currentSegmentFramesDone;
            if (encodedFrames % 10 == 0) report(ExportStage::Rendering);
        }
        if (canceled || !result.error.isEmpty()) break;

        if (segment + 4 < timing.segmentCount && segment >= 3) {
            if (!router.closeThrough(segment - 3, &error)) {
                result.error = error;
                break;
            }
        }
        report(ExportStage::Rendering);
    }

    std::vector<EncodedPacket> videoTail;
    if (!canceled && result.error.isEmpty()) {
        if (!videoEncoder.flush(&videoTail, &error)) {
            result.error = error;
        }
        for (const EncodedPacket &packet : videoTail) {
            if (!router.routeVideo(packet, &error)) { result.error = error; break; }
        }
    }

    // Always close file handles. On cancel/failure the partially written last
    // segment is deleted; only fully validated segments count as complete.
    const bool successSoFar = !canceled && result.error.isEmpty();
    const bool success = router.finishAll(successSoFar, &error);
    if (!success && result.error.isEmpty())
        result.error = error;
    checkpoint.completedSegments = success
        ? timing.segmentCount
        : std::min(timing.segmentCount,
                   startSegment + router.completedSegments());
    checkpoint.bytesWritten = router.bytesWritten();
    checkpoint.lastError = result.error;
    checkpoint.save(checkpointPath, nullptr);

    if (canceled) {
        result.canceled = true;
        result.resumable = checkpoint.completedSegments > 0;
        result.audioPeak = peak;
        return result;
    }
    if (!result.error.isEmpty()) {
        result.resumable = checkpoint.completedSegments > 0;
        result.audioPeak = peak;
        return result;
    }

    report(ExportStage::Finalizing);
    const QString temp = assemblyTempPathFor(result.outputPath);
    if (!Mp4Assembler::assemble(partsDir, audioPartPath, timing,
                                frozenSettings.fps, videoEncoder.context(),
                                audioEncoder.context(),
                                audioEncoder.encoderDelaySamples(),
                                paddedSamples, temp, &error)) {
        result.error = error;
        result.resumable = true;
        result.audioPeak = peak;
        return result;
    }
    report(ExportStage::Validating);
    result.validation = validateExportFile(temp, frozenSettings, timing);
    if (!result.validation.ok) {
        result.error = QStringLiteral("导出文件校验失败：%1")
                           .arg(result.validation.error);
        result.resumable = true;
        result.audioPeak = peak;
        return result;
    }
    if (QFileInfo::exists(result.outputPath)
        && !QFile::remove(result.outputPath)) {
        result.error = QStringLiteral("无法覆盖已存在的导出文件：%1")
                           .arg(result.outputPath);
        result.audioPeak = peak;
        return result;
    }
    if (!QFile::rename(temp, result.outputPath)) {
        result.error = QStringLiteral("无法写入最终导出文件：%1")
                           .arg(result.outputPath);
        result.audioPeak = peak;
        return result;
    }
    clearParts(partsDir);
    result.ok = true;
    result.audioPeak = peak;
    QStringList allWarnings;
    const QString hardwareWarning = result.warning; // set before rendering
    if (!hardwareWarning.isEmpty())
        allWarnings.append(hardwareWarning);
    if (orphanClipCount > 0) {
        allWarnings.append(QStringLiteral(
            "有 %1 个片段引用的素材缺失，已按黑场处理。").arg(orphanClipCount));
    }
    if (!warnings.isEmpty()) {
        allWarnings.append(QStringLiteral("部分素材无法解码，已按黑场处理：\n")
                           + warnings.join(QStringLiteral("\n")));
    }
    result.warning = allWarnings.join(QStringLiteral("\n"));
    report(ExportStage::Done);
    return result;
}
```

`percent` 公式：`Preparing=0/2/3`，`Rendering = 5 + 85 * (completedSegments + withinSegmentFraction) / totalSegments`，`Finalizing=92`，`Validating=96`，`Done=100`。`report` 中 `completedFrames` 用 `std::min<int64_t>(encodedFrames, timing.totalFrames)`，`withinSegmentFraction` 用当前段内已编码帧/段帧数；实现时把 `encodedFrames` 按引用捕获。`etaMs` = `elapsed * (totalFrames - encodedFrames) / max(1, encodedFrames)`。

`refreshValidation()`：

```cpp
void ExportController::refreshValidation()
{
    const QString error = validate();
    if (error != m_validationError) {
        m_validationError = error;
        emit validationErrorChanged();
    }
    // Re-evaluate H.265 gating for the current codec/resolution.
    const bool available = m_catalog.hasHardware(ExportVideoCodec::H265);
    if (available != m_h265Available) {
        m_h265Available = available;
        emit h265AvailableChanged();
    }
    QString reason;
    if (!available)
        m_catalog.selectEncoder(ExportVideoCodec::H265, true, nullptr, &reason);
    if (reason != m_h265UnavailableReason) {
        m_h265UnavailableReason = reason;
        emit h265UnavailableReasonChanged();
    }
    const bool resume = canResume();
    if (resume != m_canResume) {
        m_canResume = resume;
        emit canResumeChanged();
    }
}
```

每个 `setXxx` 的固定写法是：若值未变直接返回；赋值；`emit xxxChanged()`；调用 `refreshValidation()`。`canResume()` 读取 `<output>.parts/checkpoint.json`，用 `exportProjectHash(m_document.project(), currentSettings())` 与检查点比对，并检查 `completedSegments > 0`。

`startExport()`：若 `running` 直接返回；`error = validate()`；非空则 `m_error = error; emit errorChanged();` 并返回。设置 `m_running=true`；取 `Project frozen = m_document.project()`；若 `m_syncRunner` 存在，构造 progress 回调（`applyProgress`）并同步调用，随后 `finishWith(result)`；否则创建 `QThread` + `ExportWorker`，`worker->setCatalog(m_catalog)`，`thread->start()`，`QMetaObject::invokeMethod(worker, "run", Qt::QueuedConnection, Q_ARG(VideoEditor::Project, frozen), Q_ARG(VideoEditor::ExportSettings, settings), Q_ARG(bool, resume))`，连接 `progress`/`finished`。`cancelExport()` 调用 `worker->cancel()`（原子标志）。`resumeExport()` 用 `m_resumeRequested=true` 后走同一路径。`finishWith(result)`：更新 `progress=1`/`statusText`/`error`/`validationSummary`/`encoderName`，`m_running=false`，清理线程（`quit`/`wait`/`deleteLater`），`refreshValidation()`，emit `finished(result.ok, result.error.isEmpty() ? statusText : error)`。

`applyProgress`：`progress = percent/100.0`；`stageText` 映射为中文（准备/渲染/封装/校验/完成/已取消/失败）；`statusText = "%1  %2/%3 帧  第 %4/%5 段"`。

`defaultOutputPath()`：`QStandardPaths::writableLocation(MoviesLocation)`，回退到 `DocumentsLocation`，文件名 `导出_yyyyMMdd_HHmmss.mp4`。

```cpp
#include <gtest/gtest.h>

#include <QDir>
#include <QTemporaryDir>

#include "D3D11Context.h"
#include "ExportEncoderCatalog.h"
#include "ExportPipeline.h"
#include "ExportTestProject.h"
#include "FfmpegSoftwareDecoder.h"
#include "MediaProbe.h"
#include "OfflineFrameRenderer.h"

using namespace VideoEditor;

double psnrRgba(const std::vector<uint8_t> &a, const std::vector<uint8_t> &b,
                int w, int h)
{
    double mse = 0.0;
    const size_t pixels = size_t(w) * size_t(h);
    for (size_t i = 0; i < pixels; ++i) {
        for (int c = 0; c < 3; ++c) {
            const double d = double(a[i * 4 + c]) - double(b[i * 4 + c]);
            mse += d * d;
        }
    }
    mse /= double(pixels * 3);
    if (mse <= 1e-9) return 99.0;
    return 10.0 * std::log10(255.0 * 255.0 / mse);
}

std::vector<uint8_t> decodeFrameRgba(const QString &path, int64_t ptsUs,
                                     int w, int h, QString *error)
{
    const auto probed = MediaProbe::probe(path, error);
    if (!probed)
        return {};
    const MediaInfo info = *probed;
    QString deviceError;
    auto device = D3D11Context::create(false, &deviceError);
    if (!device) {
        if (error) *error = deviceError;
        return {};
    }
    auto decoder = FfmpegSoftwareDecoder::open(path, *device, info, error);
    if (!decoder) return {};
    if (!decoder->seek(ptsUs, error)) return {};
    DecodedFrame frame;
    if (!decoder->decodeNext(frame, error)) return {};
    if (frame.rgba.empty()) {
        if (error) *error = QStringLiteral("decoded frame has no RGBA data");
        return {};
    }
    std::vector<uint8_t> result = frame.rgba;
    result.resize(size_t(w) * size_t(h) * 4);
    return result;
}
```

```cpp
void AppController::selftestExport()
{
    // Reuse the M2 3V/2A/1S project builder; export is deliberately tested
    // against the same timeline the preview performance gate uses.
    buildTimelineSelftestProject();
    Project project = m_document->project();
    if (project.assets.size() < 3) {
        qCritical("EXPORT_SELFTEST_FAIL missing fixtures");
        QCoreApplication::exit(5);
        return;
    }
    project.timeline.width = 640;
    project.timeline.height = 360;
    project.timeline.fps = Rational{30, 1};

    const QString root = QDir(QDir::tempPath())
                             .filePath(QStringLiteral("videoeditor-export-selftest"));
    QDir(root).removeRecursively();
    if (!QDir().mkpath(root)) {
        qCritical("EXPORT_SELFTEST_FAIL cannot create %s", qPrintable(root));
        QCoreApplication::exit(5);
        return;
    }
    const EncoderCatalog catalog =
        detectEncoders(project.timeline.width, project.timeline.height,
                       project.timeline.fps);
    QStringList done;
    int64_t maxAvDiffUs = 0;
    for (ExportVideoCodec codec : {ExportVideoCodec::Mpeg4Part2,
                                   ExportVideoCodec::H264,
                                   ExportVideoCodec::H265}) {
        bool hardware = false;
        QString reason;
        const QString encoder = catalog.selectEncoder(codec, true, &hardware,
                                                      &reason);
        if (encoder.isEmpty()) {
            qInfo("EXPORT_SELFTEST_SKIP codec=%s reason=%s",
                  qPrintable(exportCodecToString(codec)), qPrintable(reason));
            continue;
        }
        ExportSettings settings;
        settings.codec = codec;
        settings.width = project.timeline.width;
        settings.height = project.timeline.height;
        settings.fps = project.timeline.fps;
        settings.rateControl = ExportRateControl::Bitrate;
        settings.bitrateKbps = 6000;
        settings.outputPath =
            QDir(root).filePath(exportCodecToString(codec) + QStringLiteral(".mp4"));
        settings.segmentTargetUs = 1'000'000;
        ExportPipeline pipeline;
        const ExportResult result = pipeline.run(project, settings, catalog,
                                                 false, {});
        if (!result.ok) {
            qCritical("EXPORT_SELFTEST_FAIL codec=%s error=%s",
                      qPrintable(exportCodecToString(codec)),
                      qPrintable(result.error));
            QCoreApplication::exit(5);
            return;
        }
        const int64_t frameUs = 1'000'000 / 30;
        const int64_t diff = std::llabs(result.validation.audioDurationUs
                                        - result.validation.videoDurationUs);
        maxAvDiffUs = std::max(maxAvDiffUs, diff);
        if (diff > frameUs + 1) {
            qCritical("EXPORT_SELFTEST_FAIL codec=%s avDiffUs=%lld",
                      qPrintable(exportCodecToString(codec)),
                      static_cast<long long>(diff));
            QCoreApplication::exit(5);
            return;
        }
        done.append(exportCodecToString(codec));
    }
    if (done.isEmpty()) {
        qCritical("EXPORT_SELFTEST_FAIL no encoder available");
        QCoreApplication::exit(5);
        return;
    }
    qInfo("EXPORT_SELFTEST_OK codecs=%s maxAvDiffUs=%lld",
          qPrintable(done.join(QLatin1Char(','))),
          static_cast<long long>(maxAvDiffUs));
    QCoreApplication::exit(0);
}
```

### 5. 已知未决风险（执行者必须在 Task 2/10 记录）

1. **H.264 软件回退的专利授权**：默认选 `h264_mf`（Windows 自带 Media Foundation 软件 MFT）；`libopenh264` 虽在 BtbN LGPL 构建中可用，但其 Cisco 专利覆盖取决于二进制来源，发布前需法务确认，默认不选。
2. **硬件编码器差异**：NVENC/QSV/AMF/MF 对 `bf`、`hw_encoding`、码率控制选项的支持不完全一致；`applyEncoderOptions` 的 `av_opt_set*` 失败被忽略，靠“探测 + 编码测试”兜底。若某驱动对 `max_b_frames=0` 不支持，`SegmentRouter` 的 packet 计数校验会以明确中文错误失败，不会写出错误文件。
3. **QSV 需要 Intel 驱动与 MFX 运行时**；无 Intel GPU 的机器会探测失败并跳过，不影响 H.264/MPEG-4。
4. **`libopenh264` 的动态/静态链接随 FFmpeg 构建而变**；本机 BtbN 包中它编进 `avcodec-61.dll`，不额外分发 DLL。
5. **AAC 编码器延迟/补齐**：通过 `initial_padding` + `discard_padding` 写入最终 MP4 的 edit list；不同播放器对 edit list 的处理可能有几毫秒差异，验收以 1 帧容差为准。
6. **1080p 硬件性能门禁依赖桌面会话与独显**；在无硬件/远程桌面环境会 `GTEST_SKIP`，需在目标配置机上手动跑一次 `export_selftest` 与 `HardwareH264IsAtLeastRealtimeAt1080p`。
