# 视频剪辑软件设计方案

- 日期：2026-11-14
- 状态：已批准，M1 实现计划已编写
- 目标平台：Windows 桌面端优先
- 技术路线：Qt 6 + C++，D3D11 统一渲染与硬件解码

## 1. 背景与目标

为专业剪辑用户开发一款 Windows 本地视频编辑软件，把日常剪辑、背景音乐、字幕、变速和基于 AI 的画面消除整合到一个非破坏性工作流中。原始素材只读，所有修改记录在工程中，可撤销、可恢复、可重新生成。

成功不仅是“能导出视频”，还包括：

- 时间线操作精确、预览流畅、音画同步。
- 常用格式能正确识别、播放和导出，不依赖扩展名猜测。
- AI 消除结果可检查、可局部返修、可完全撤销。
- 工程在异常退出后可以恢复。

## 2. 用户与成功标准

**目标用户**：专业剪辑用户，熟悉多轨时间线、关键帧、时间码和字幕工作流。

**成功标准（首版）**

1. 能完成一条 1080p 短片的完整制作：导入、剪辑、配乐、字幕、变速、AI 消除、导出。
2. 时间线操作可精确到帧，撤销/重做可靠。
3. 预览与导出结果一致，没有“预览正常、成片出错”。
4. AI 消除在静态与运动目标上均可完成遮罩跟踪和局部重做。
5. 支持矩阵内的格式全部可导入，三种编码均可导出 MP4。

## 3. 范围

### 3.1 首版包含

- 多轨视频剪辑：移动、裁切、分割、波纹删除、音视频链接、逐帧定位、吸附。
- 背景音乐编辑：本地音频导入、波形、剪切、音量、声像、淡入淡出、音量关键帧。
- 字幕：独立字幕轨、逐条时间编辑、样式与位置、SRT 导入导出、烧录输出。
- 变速：片段级固定倍速 0.25–4 倍，可选保持音高。
- AI 消除：静态与运动目标，本地推理，遮罩跟踪、关键帧修正、局部重做、原片对比。
- 格式：WMV/VC-1 导入；MP4 的 MPEG-4 Part 2、H.264、H.265 导入与导出。
- 工程安全：自动保存、崩溃恢复、素材丢失定位、缓存管理。
- 1080p SDR（BT.709）为主的工作流；4K 可导入，不承诺原分辨率多轨实时预览。

### 3.2 首版不包含

- 自动语音识别字幕、语音转写。
- 云端处理、云端协作、素材上传。
- 在线曲库、自动作曲、AI 配乐。
- 速度曲线、光流补帧、慢动作插帧。
- 完整调色系统、LUT 管理、HDR 端到端工作流。
- WMV 导出。
- 多机位编辑、代理工作流之外的复杂媒体管理。
- Vulkan、OpenGL、D3D12 渲染后端；首版统一使用 D3D11。

## 4. 功能需求

### 4.1 工程

- 工程包含时间线设置、轨道、片段、字幕、音频参数和素材引用。
- 工程文件为版本化格式，保存时原子写入，支持向前兼容迁移。
- 默认每 30 秒及关键操作后自动保存；异常退出后启动时提供恢复副本。
- 原始素材只读；删除工程不删除源文件。

### 4.2 时间线与剪辑

- 视频轨、音频轨、字幕轨分层，顺序可调整。
- 支持移动、裁切入出点、分割、删除、波纹删除、复制、粘贴、吸附。
- 同一素材可多次引用；音视频默认链接，可解链与重新链接。
- 所有编辑通过可撤销命令执行，撤销栈至少保留 100 步。
- 支持逐帧前进/后退、时间码显示与跳转、时间线缩放。

### 4.3 背景音乐

- 支持 WAV、MP3、AAC/M4A、FLAC 导入，显示波形。
- 音频片段可分割、裁切、移动，可设置音量、声像、淡入淡出。
- 支持音量关键帧；实时混音不应削波，导出音频不得削波。
- 原视频声音与背景音乐分轨控制，可单独静音或独奏。
- 首版不包含变调、均衡器、压缩器等音频效果器。

### 4.4 字幕

- 独立字幕轨，每条字幕有入点、出点、文本和样式。
- 支持字体、字号、颜色、描边、背景、对齐、安全区内位置。
- 支持样式预设，可对单条或全部字幕应用。
- 支持 SRT 导入与导出；导入时处理时间码解析和编码问题。
- 预览与导出默认烧录字幕；可选择导出 SRT 作为独立文件。软字幕轨（mov_text）不在一版范围。

### 4.5 变速

- 片段级固定倍速，范围 0.25–4 倍；时长随倍速同步变化。
- 可选保持音高；使用时域伸缩处理，不改变音高时允许自然变速。
- 变速后的片段仍可继续裁切、分割和加字幕。
- 首版不做速度曲线和光流插帧；快速播放按帧采样/帧混合处理。

### 4.6 AI 消除

- 用户以画笔涂抹或框选生成目标区域，支持羽化和边缘修正。
- 系统可对目标做逐帧跟踪并传播遮罩，显示每段跟踪置信状态。
- 用户可修正关键帧遮罩，修正后重新传播相邻区间。
- 修复结果按时段生成，写入缓存；预览中可对比原片与修复结果。
- 修复结果作为生成层参与合成，不修改原素材；可删除、禁用或局部重做。
- 支持静态目标（台标、水印、固定物体）和运动目标（行人、车辆等）。
- 全部推理在本地完成，不上传素材。

### 4.7 导入与检查

- 导入时探测容器和实际编码，不依赖扩展名。
- 显示分辨率、帧率、时长、视频编码、音频编码、像素格式、色彩范围等关键信息。
- 不支持的编码明确提示原因，并提供转码建议。
- 素材丢失时保留占位，允许重新定位；不自动删除引用。

## 5. 格式支持

### 5.1 术语定义

- **容器/文件格式**：MP4、WMV。负责封装视频、音频和元数据。
- **视频编码**：MPEG-4 Part 2、H.264（MPEG-4 Part 10/AVC）、H.265（HEVC）、WMV3/VC-1。
- 需求中的“MPEG-4”在本设计中指 **MPEG-4 Part 2**；H.264 单独列出，不混为一谈。
- WMV 文件的实际视频编码通常为 WMV3 或 VC-1，导入按实际流处理。

### 5.2 导入/导出矩阵

| 方向 | 容器 | 视频编码 | 音频编码 | 策略 |
|---|---|---|---|---|
| 导入 | MP4 | MPEG-4 Part 2 | AAC / MP3 | 软件解码 |
| 导入 | MP4 | H.264 | AAC | 硬件解码优先，软件兜底 |
| 导入 | MP4 | H.265/HEVC | AAC | 硬件解码优先；不支持时提示 |
| 导入 | WMV/ASF | WMV3 / VC-1 | WMA | FFmpeg 解码 |
| 导出 | MP4 | MPEG-4 Part 2 | AAC | 软件编码，兼容性兜底 |
| 导出 | MP4 | H.264 | AAC | 硬件编码优先，软件兜底 |
| 导出 | MP4 | H.265/HEVC | AAC | 仅硬件编码，导出前检测能力 |

**编码不可用时的行为**：H.265 导出在无可用硬件编码器时禁用并说明原因；不得静默改成其他编码或输出不可播放文件。

### 5.3 导入管线

1. 探测容器、视频流、音频流、时长、色彩信息和旋转元数据。
2. 建立统一时间基；变帧率素材统一归一化为恒定帧率后再编辑。
3. 应用显示旋转信息，保证预览方向正确。
4. 生成缩略图与音频波形。
5. 高码率或 4K 素材后台生成代理媒体；默认代理为半分辨率、恒定帧率、全帧内编码，1080p 素材可手动开启。

### 5.4 导出管线

1. 冻结工程快照，计算输出总时长与帧数。
2. 分段离线渲染，复用预览的合成逻辑。
3. 编码视频与音频，封装为 MP4。
4. 写入前校验：时长、帧率、音轨存在、AAC 参数、容器兼容性。
5. 导出过程中保留检查点，可取消；失败后可续跑。
6. 完成后校验文件可被重新探测和播放。

**导出选项**：分辨率、帧率、码率或质量档位、硬件/软件编码器、字幕是否烧录、SRT 是否同时导出。

### 5.5 预览

- 优先使用 D3D11VA/NVDEC 硬件解码，失败回退软件解码。
- 解码帧进入有界帧缓存，避免内存无上限增长。
- 音频作为主时钟，视频按时间戳对齐；落后时丢帧而不是拖慢播放。
- 支持预览清晰度切换（全质量 / 半质量 / 代理），不改变最终导出质量。
- 1080p SDR、BT.709、有限范围为基础工作流；HDR 素材首版提示不支持完整色彩管理。

## 6. 总体架构

### 6.1 进程与线程

- **界面进程**：Qt Quick/QML 界面（D3D11 RHI 后端）、工程核心、预览合成、音频输出。UI 线程只处理交互。
- **媒体工作线程池**：解码、合成、编码。解码使用独立 D3D11 设备，帧写入共享纹理，由 Qt 场景图线程桥接；不经过 CPU 读回。
- **音频线程**：低延迟混音与输出，提供播放主时钟。
- **AI 子进程**：独立运行推理，通过本地 IPC 接收任务和返回结果；可限制资源，崩溃不影响工程。
- **导出子进程或工作线程**：离线渲染不阻塞界面，支持取消和检查点。

### 6.2 模块职责

| 模块 | 职责 | 对外接口 | 依赖 |
|---|---|---|---|
| UI 层 | 交互、显示、快捷键、拖拽 | 发送命令；订阅状态快照 | Qt 6 |
| Project Model | 工程数据与校验 | 读写、迁移、快照 | 存储层 |
| Command / Undo | 可撤销修改 | `apply()` / `revert()` | Project Model |
| Timeline Evaluator | 计算某时刻的图层与叠加关系 | `frameAt(time)`、`audioRange()` | 工程数据 |
| Media Decoder | 探测、解码、代理、帧缓存 | 统一帧与音频块输出 | FFmpeg、D3D11 |
| Preview Renderer | 合成画面、字幕、AI 生成层 | 输出预览纹理 | Decoder、Timeline |
| Audio Engine | 混音、增益、淡入淡出、主时钟 | PCM 输出、播放时钟 | WASAPI |
| Exporter | 离线渲染、编码、封装、校验 | 进度、检查点、输出文件 | Decoder、Renderer |
| AI Engine | 分割、跟踪、遮罩传播、修复 | 任务协议（JSON + 结果文件） | ONNX Runtime、GPU |
| Asset Manager | 素材定位、代理、缩略图、缓存 | 路径解析、缓存键、清理 | 存储层 |

### 6.3 边界原则

- AI 引擎只接受“帧序列 + 遮罩 + 参数”，返回“修复帧序列”；不了解工程结构。
- 导出器与预览共用同一合成实现，防止结果分叉。
- 模块之间通过明确的数据结构交互，不共享可变全局状态。
- 每个模块可独立测试；核心逻辑不依赖 UI。

## 7. 数据模型

### 7.1 工程

```
Project
  schemaVersion
  name
  timeline: { width, height, fps, sampleRate, colorSpace }
  assets[]        // 素材引用、探测信息、代理路径
  tracks[]
  subtitleStyles[]
  createdAt / updatedAt
```

### 7.2 时间线

```
Track
  type: video | audio | subtitle
  clips[]
  enabled / muted / locked

Clip
  assetId
  sourceIn / sourceOut       // 源素材时间
  timelineStart              // 时间线起始
  speed                      // 0.25–4
  preservePitch
  volume / pan / fade        // 音频片段
  keyframes[]                // 音量等参数
  removalLayerId?            // 关联的 AI 生成层
  enabled

SubtitleCue
  text
  start / end
  styleId
  position
```

所有时间使用有理数时间基，避免浮点累积误差；帧号与时间码可相互换算。

### 7.3 AI 生成层

```
RemovalLayer
  clipId
  range: { start, end }         // 时间线区间
  maskKeyframes[]               // 时间 + 遮罩位图引用
  trackingState                 // 完成 / 部分 / 低置信
  parameters                    // 羽化、修复模式、分辨率
  cacheKey                      // 素材哈希 + 遮罩 + 参数 + 模型版本
  cachePath
  revision
```

修改遮罩或参数会产生新 `cacheKey`，旧缓存可安全淘汰；删除生成层即恢复原片。

### 7.4 存储与缓存

- 工程文件：版本化 JSON（UTF-8），原子写入；默认扩展名 `.veproj`。
- 缓存目录：`%LOCALAPPDATA%\<产品名>\cache\`，按内容哈希分目录。
- 缓存内容：代理媒体、缩略图、波形、AI 修复结果、渲染中间帧。
- 缓存可重建、可清理；清理不影响工程正确性，只会触发重算。
- 崩溃恢复副本与日志分开存放，便于诊断。

## 8. 数据流

1. **导入**：探测 → 记录流信息 → 缩略图/波形 → 兼容性判定 → 必要时生成代理。
2. **编辑**：UI 命令 → Core 校验 → 写工程 → 撤销栈 → 时间线增量刷新。
3. **预览**：播放时钟请求帧 → 解码缓存 → 合成图层与字幕 → 显示；音频线程驱动主时钟。
4. **AI 消除**：选区 → 遮罩关键帧 → 跟踪 → 修复渲染 → 结果缓存 → 生成层记录 → 预览/导出合成。
5. **导出**：冻结快照 → 分段渲染 → 编码封装 → 校验 → 完成通知。

## 9. 关键实现策略

### 9.1 合成与预览

- 图形后端统一为 D3D11：Qt Quick 使用 D3D11 RHI，视频解码使用 D3D11VA。解码在独立 D3D11 设备与线程中进行，通过共享纹理和键控互斥量桥接到 Qt 场景图设备，再用 `QNativeInterface::QSGD3D11Texture` 包装为 `QSGTexture`；全程不经过 CPU 读回，允许一次 GPU 内拷贝。选择理由：Windows 上硬件解码与硬件编码的互通最成熟；Vulkan 的 FFmpeg 视频解码与编码链路仍不成熟，OpenGL 与 D3D11VA 的互通依赖厂商扩展，均不适合作为首版主路径。
- 渲染层保留轻量抽象：对外暴露“GPU 纹理句柄 + 格式 + 同步状态”，首版只实现 D3D11；未来若确认跨平台，再增加 Vulkan 后端，不提前实现。
- 导出路径独立于 UI：无论界面如何绘制，编码仍使用 D3D11 纹理配合 NVENC/QSV/AMF 或软件编码器。
- 图层按轨道顺序合成；AI 生成层替换对应片段画面，随后叠加字幕，保证字幕始终位于最上层。
- 合成参数（缩放、位置、不透明度）首版保持最小必要集合。
- 预览与导出使用相同的时间映射和合成函数；差异仅在输出分辨率、质量和调度策略。
- 帧缓存按时间与图层索引命中；内存上限可配置，超出后按最近最少使用淘汰。

### 9.2 音频

- 48 kHz 浮点内部混音，输出到 WASAPI。
- 使用音频播放位置作为主时钟；视频根据时钟选择显示帧。
- 变速使用时域伸缩；保持音高时使用适合实时预览的轻量算法，导出时使用更高质量设置。
- 淡入淡出与音量关键帧在混音阶段应用；导出前检测峰值，必要时整体限幅并提示。

### 9.3 AI 消除流水线

1. 首帧遮罩：用户在参考帧涂抹或框选，生成二值遮罩。
2. 分割与跟踪：逐帧传播遮罩，输出置信度与可见性。
3. 修复：参考前后帧重建被遮挡背景；静态目标可使用单帧或低时序修复。
4. 时域后处理：抑制闪烁、颜色匹配、边缘融合。
5. 缓存与回写：按区间写入缓存，工程仅记录引用。
6. 返修：修改关键帧后，只重新传播并重算受影响区间。

**资源管理**：显存不足时降低处理分辨率或分块处理；任务可暂停、取消、续跑；推理进程崩溃后任务标记失败，用户可重试。

## 10. 错误处理与恢复

| 场景 | 行为 |
|---|---|
| 编码不支持 | 说明具体原因，建议转码；不加入时间线 |
| 文件损坏 | 报告损坏位置；已成功探测的流仍可尝试使用 |
| 权限或路径问题 | 明确提示，允许重新定位素材 |
| 硬件解码/编码不可用 | 自动回退软件路径，说明性能影响 |
| 显存不足 | 降低 AI 处理规格或暂停任务，保留进度 |
| 磁盘空间不足 | 停止写入，保留检查点，提示清理缓存 |
| 导出中断 | 保留已完成分段，修复后续跑 |
| 异常崩溃 | 启动时检测未正常关闭工程，提供恢复副本 |
| 音画不同步 | 以音频时钟重新对齐；导出前检查时长与时间戳 |

所有错误信息面向剪辑用户，说明发生了什么、影响是什么、可以怎么做。

## 11. 测试与验收

### 11.1 测试层级

| 层级 | 内容 |
|---|---|
| 单元测试 | 工程模型、命令撤销、时间线求值、变速时长、SRT 解析、时间码换算 |
| 合成测试 | 固定素材逐帧输出，与基准帧比对，确保预览与导出一致 |
| 音画同步 | 节拍与计数帧测试素材，校验任意位置偏差 |
| 格式矩阵 | 自动生成 MPEG-4 Part 2、H.264、H.265 的 MP4 与 WMV/VC-1 素材，覆盖导入、预览、导出 |
| AI 评估 | 静态与运动目标样本，检查遮罩覆盖率、时域闪烁、人工主观评分、撤销与局部重做 |
| 健壮性 | 损坏文件、强制结束进程、磁盘写满、GPU 掉线、驱动重置 |
| 性能 | 1080p 多轨预览帧率、代理切换耗时、导出速度、内存峰值 |

### 11.2 验收标准

1. MP4 的三种编码与 WMV/VC-1 均能正确导入并显示元数据；不支持时有明确提示。
2. 剪切、分割、变速后无黑帧、无音画漂移；变速支持 0.25–4 倍并可选保持音高。
3. 背景音乐可剪切、调音量、淡入淡出和音量关键帧，导出无削波。
4. 字幕可逐条编辑并与 SRT 双向导入导出，烧录位置准确到帧。
5. 静态与运动目标的消除可跟踪、可修正关键帧、可局部重做、可完全撤销。
6. 三种编码均可导出 MP4；音画时长偏差不超过一帧；常见播放器可正常播放。
7. 异常退出后可恢复工程；素材丢失可重新定位且不破坏引用。

### 11.3 性能目标

以 1080p、30/60fps 工程为基准。推荐配置定义为：6 核以上 CPU、16 GB 内存、GTX 1060 / RTX 3050 及以上级别 GPU、SSD 存储。

- 3 条视频轨 + 2 条音频轨 + 1 条字幕轨，预览不低于 24 fps。
- 导出 H.264 1080p30 不低于 1 倍实时（硬件编码）。
- AI 修复 1080p30、10 秒片段，在 RTX 3060 级别 GPU 上不超过 10 分钟。
- 预览内存峰值可控，缓存达到上限后稳定，不持续增长。

## 12. 风险与选型门禁

| 风险 | 影响 | 应对 |
|---|---|---|
| AI 模型许可证限制 | 无法商业发布 | 选型阶段逐一核对许可证；只采用允许商用的模型 |
| 时域修复闪烁、遮挡复杂 | 效果不达标 | 支持关键帧修正和局部重做；建立固定评估样本 |
| H.264/H.265 专利授权 | 发行合规风险 | 优先硬件编码器并取得授权；发布前法务确认 |
| Qt / FFmpeg 许可证 | 发行方式受限 | Qt 采用 LGPL 动态链接或商业授权；FFmpeg 使用不含 GPL 组件构建 |
| 硬件多样性 | 解码/编码表现不一致 | 覆盖 NVIDIA/Intel/AMD 测试；始终保留软件回退 |
| 驱动重置或 GPU 掉线 | 任务中断 | 检测设备丢失，自动切换软件路径并提示 |
| 变帧率素材 | 时间线漂移 | 导入时归一化为 CFR 并记录原始信息 |
| 手机旋转元数据 | 预览方向错误 | 导入时应用显示矩阵并验证 |
| 未来跨平台需求 | 需要补 Vulkan 后端 | 渲染边界保持抽象；首版不实现 Vulkan，确认需求后再投入 |
| 图形驱动差异 | 合成或显示异常 | 以 D3D11 为唯一路径并覆盖 NVIDIA/Intel/AMD 测试；设备丢失时重建资源 |

**选型门禁**（进入实现前必须确认）：

- 分割/跟踪与修复模型的具体版本、许可证和商业使用条件。
- H.264 软件编码回退方案（硬件不可用时的可用编码器）及其授权。
- H.265 编码器的最低硬件要求和不可用时的产品提示。
- Qt 与 FFmpeg 的最终构建方式与分发义务。

## 14. 已确认决策摘要

- 目标用户：专业剪辑用户。
- 平台：Windows 桌面端优先。
- 技术路线：Qt 6 + C++，FFmpeg 媒体引擎，D3D11 硬件加速。
- AI：本地推理，静态与运动目标，ONNX Runtime；不上传素材。
- 字幕：手动编辑 + SRT；首版不做语音识别。
- 格式：WMV/VC-1 导入；MP4 的 MPEG-4 Part 2、H.264、H.265 导入与导出；H.265 导出依赖硬件编码。
- 性能基线：1080p、30/60fps；4K 可导入但不承诺原分辨率多轨实时预览。
- 编辑模型：非破坏性，生成层可撤销、可重建。
- 图形后端：D3D11 统一 UI、解码与合成；首版不做 Vulkan/OpenGL 后端，保留轻量抽象以便未来扩展。
- 预览帧桥接：独立解码设备 + 共享纹理，GPU 内单次拷贝，无 CPU 回读；使用 Qt 公共接口 `QNativeInterface::QSGD3D11Texture` 显示。
